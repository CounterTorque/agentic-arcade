# Pour It Up

## Concept

Fill a glass from the tap to the dashed line. Release in the green band for a perfect pour; too little, too much, or a spill loses.

## Controls

Hold Space, Enter, Z, J, or left click to pour. Release to stop.

## Difficulty

Speed multiplies the flow rate. The level changes the glass and the accuracy required:

| Level | Rate at speed 1 | Tolerance | Glass width | Surge |
|---|---|---|---|---|
| 1 | 25% per second | ±6% | 220 px | none |
| 2 | 35% per second | ±4% | 170 px | none |
| 3 | 50% per second | ±3% | 140 px | ±15% |

## Tuning

The target line is 70% of the glass height. Level 3's flow surges smoothly with a 600 ms period at speed 1; the surge also speeds up with the game. At level 3 and speed 2.5 the release window is roughly 50 ms. A pour still held when time expires is judged at its current level.
